# 控制台表面用炭灰与铜

Web Studio 的控制台表面是暗色工具面。海军蓝加青把页面、选中和主操作染成同一冷色。底用中性炭灰，铜只标记可提交的操作和键盘焦点。

## 决定

- 只做暗色。页面 `#1B1D1F`，面板 `#242628`，输入框 `#141618`，正文 `#E6E4DF`，次级文字 `#A39E96`，边框 `#3C3A36`。
- 实心主按钮和焦点环用铜 `#E08A2C`，按钮文字 `#1A1208`。标志、图标、选中、链接、复选框、行内代码、文字选区和类型胶囊用骨色或炭灰。
- 状态胶囊保持语义色：直连与健康用翠绿，阻断与拦截用玫红，警告用琥珀描边。
- 界面用系统无衬线，标签、正则、计数和延迟用等宽。主行维持现有密度。
- 圆角 2–4px。卡片不投影。模糊只留固定顶栏。

## 未采用

- 冷海军蓝加青：现有表面，冷色互相抢。
- 墨底染褐：铜在褐底上发脏。
- Grafana 炭灰加蓝：底可用，蓝按钮会把铜让回去。橙在 Grafana 里表示偏高，不表示保存。
- 石墨加冰蓝、青瓷绿：分别是通用暗色后台和终端仪表盘模板。

## 影响

交互范式仍以 ADR 0016 为准。该 ADR 的青色条款由本文取代。界面代码尚未改。
