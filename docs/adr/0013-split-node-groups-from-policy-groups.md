# 拆分出站策略组与节点分组

扩展 [ADR 0012](0012-web-studio-producer-coexistence.md)：在 Web Studio 配置模板（Template）中将出站策略组与节点分组显式拆分为两层结构。

## 背景

此前 Web Studio 模板中所有的出站（包括面向路由分流的业务策略组、用于按地域/正则聚合节点的测速分组、以及基础直连出站）均混杂在单一平铺的 `outbounds` 数组中。这导致业务策略组与底层节点筛选逻辑耦合，用户容易在策略组中随意填写正则模式或直接引用未分组的单个节点，造成分流逻辑混乱且缺乏语法层面的约束。

## 决定

1. **模板结构解耦**：
   - 模板 `content` 显式分为 `policy_groups`（出站策略组）、`node_groups`（节点分组）与基础 `outbounds`（直连/拒绝出站）。
   - **节点分组 (`node_groups`)**：负责通过正则占位符（如 `{(?i)(港|hk)}`）或标签筛选并聚合节点源中的代理节点，设定测速容差与调度算法（`urltest` / `selector`）。
   - **出站策略组 (`policy_groups`)**：承载路由分流规则与 DNS Detour 的业务出口（如默认策略、AI、流媒体），其候选出站严格仅允许从已定义的 `node_groups` 标签及系统合法基础出站（`直连` / `direct` / `reject` / `block`）中挑选。策略组禁止填入正则占位符，亦禁止策略组之间循环嵌套。

2. **纯净编译与装配契约**：
   - 配置编译（Compilation）在标签展开阶段首先遍历 `node_groups` 匹配节点源中的代理节点并生成命中列表。
   - 展开完成后，将 `policy_groups`、基础直连出站、展开后的 `node_groups` 以及实际被引用的代理节点按序装配进最终 sing-box 配置的根 `outbounds` 数组中，并在输出中剔除 `policy_groups` 与 `node_groups` 顶层字段，保证生成 100% 符合 sing-box 规范的配置。

3. **界面引导与校验收紧**：
   - Web Studio 模板编辑器提供两个独立的子面板：「出站策略组」与「节点分组」。
   - 出站策略组编辑器的候选目标去除文本模式，改为只读可选项（仅列出当前模板的节点分组与直连出站）。
   - 后端 `validate_template_content` 对策略组引用目标施加硬性引用校验，非法引用即时阻断保存。
